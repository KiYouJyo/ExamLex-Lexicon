# ExamLex Lexicon A1 pilot v0.2 — attribution

This version is a **small, manually selected, Oxford-referenced A1-oriented
pilot**. It is NOT the complete Oxford A1 list and the selection was not
independently verified against the whole official list. This build contains
no Oxford dictionary definitions.

Lexical definitions, sense divisions, source parts of speech, pronunciations,
inflections, and example material originate from the **full English Wiktionary**
(https://en.wiktionary.org/) via the Kaikki.org / Wiktextract English dictionary:
https://kaikki.org/dictionary/English/
https://kaikki.org/dictionary/rawdata.html

This release uses the per-word JSONL files located below
https://kaikki.org/dictionary/English/meaning/ (not the Simple Wiktionary
dataset used in the old v0.1 pilot).

Original content is subject to applicable Wiktionary CC BY-SA/GFDL terms,
including attribution and share-alike obligations. See the Wiktionary page
history for contributors. Wiktextract is by Tatu Ylonen:
https://github.com/tatuylonen/wiktextract

Oxford's reference wordlists and definitions are copyrighted and are not
redistributed by this repository; consult:
https://www.oxfordlearnersdictionaries.com/terms-and-conditions

The A1 value is intentionally an **entry-level learning filter**, not a
guarantee that each imported Wiktionary sense is CEFR A1. The source parts
of speech and independently documented senses are retained rather than
rewritten by AI or merged merely because their definitions are similar.

Read a1-import-report.json for any missing headwords or headword/POS pairs.
The original v0.1 release remains available as an immutable older pilot.
